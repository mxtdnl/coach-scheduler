# Coaching Meeting Scheduler

A browser-based tool that allocates recurring 1-hour coaching meetings to students and coaches for a 15-week term: it reads Excel uploads (class timetable, coach availability, student list, and an optional student–coach pairings file), computes a clash-free schedule under fixed cadence rules, and exports one Excel row per appointment. It runs entirely in the browser — no server, no build step, and no data ever leaves your laptop. See `SPEC.md` for the full technical specification and `BUILD_GUIDE.md` for how this project is assembled session by session.
