Term Scheduler

Runs in your browser. Files are never uploaded to a server. Calendar icons created by SBTS2018 - Flaticon

Set up the term

Choose the term start date and how students are matched to coaches.

Term start date

Pick any date in the first week of the term. It is normalised to the Monday of that week.

Campus

All meetings in a run take place at one campus. Its local time zone is used for the exported meeting times, including the correct offset either side of a daylight saving change.

Assignment mode

Choose how students are matched to coaches.

Templates

Download, fill in, and upload these on the next step. Pairings is only needed in pre-allocated mode. The class schedule and student list both carry a Class Block column: each class block is one cohort's timetable, expected to total 13.5 hours, and every student belongs to one of them.

  • Coach availability template
  • Student list template
  • Pairings template

Upload files

Drag and drop each file, or click to choose one. Each file is checked as soon as it is read.

Class schedule

One row per class, each naming its class block. A class block is one cohort's whole timetable and is expected to total 13.5 hours. A block that comes to anything else is flagged, but the file is still accepted.

Coach availability

The weekly windows each coach can meet students in.

Student list

One row per student, with the Salesforce contact ID and the class block they belong to.

Pairings

Required in pre-allocated mode.

Review capacity

Coach capacity and FTE for the 15 term weeks.

Edit the schedule

Move, place or swap a student's whole placement. No edit is required.

Results

The schedule, exceptions, and bookings appear here.
