# Sample data

Dummy data for exercising the app end to end. The blank templates in
`templates/` are unchanged — these are filled copies with the same columns,
sheet names and legend rows, regenerated by `tools/generate_sample_data.py`.

| File | Contents |
| --- | --- |
| `class_schedule_sample.xlsx` | 2 class blocks, 13.5 hours each, 6 classes per block in 1.5–3 hour windows |
| `students_sample.xlsx` | 95 students, unique Contact SF IDs, split 48 / 47 across Block A and Block B |
| `coach_availability_sample.xlsx` | 7 coaches, 95 one-hour windows spaced an hour apart (09:00–10:00, 11:00–12:00, …) — 16 windows each for five coaches, 9 for one, 6 for one |

Block A runs mornings and Block B afternoons, so a coach window blocked for one
cohort's class stays usable by the other. Together the files parse without
errors or warnings and schedule all 95 students in auto mode (89 usable slots,
62 valid for each block).

There is no pairings sample — that file is only needed in pre-allocated mode.

Regenerate with:

```sh
python3 tools/generate_sample_data.py
```
